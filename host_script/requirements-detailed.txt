# PiCoMonitor Detailed Requirements
# ==================================

# Core Requirements (Required)
# ----------------------------
psutil>=5.9.0,<6.0.0          # System monitoring (CPU, memory, disk, sensors)
pyserial>=3.5,<4.0          # Serial communication with Raspberry Pi Pico
pystray>=0.19.0,<1.0        # System tray icon and menu
Pillow>=10.0.0,<11.0        # Image creation for system tray icon
pythonnet>=3.0.0,<4.0       # .NET interop for OpenHardwareMonitor

# Platform-Specific Requirements
# ------------------------------
pywin32>=300,<400            # Windows-specific functionality (required on Windows)

# Development & Testing Requirements
# ----------------------------------
argparse>=1.4.0,<2.0        # Command line argument parsing (usually built-in)

# Optional Enhancements
# ---------------------
# The following are optional but recommended:

# For better logging:
# coloredlogs>=15.0.0,<16.0

# For configuration file support:
# PyYAML>=6.0.0,<7.0

# For advanced error handling:
# sentry-sdk>=1.0.0,<2.0

# Installation Notes
# ------------------
# 1. Install core requirements:
#    pip install -r requirements.txt
#
# 2. For Windows users, ensure pywin32 is installed:
#    pip install pywin32
#
# 3. OpenHardwareMonitorLib.dll must be placed in the OpenHardwareMonitor directory
#    or the path updated in the script.
#
# 4. On Linux, you may need additional system packages:
#    sudo apt-get install python3-dev libatlas-base-dev

# Version Compatibility Notes
# ---------------------------
# - Python 3.8+ required
# - Tested with Python 3.12
# - Windows 10/11 and Linux (Ubuntu/Debian) supported
# - Raspberry Pi Pico requires CircuitPython or MicroPython with serial support
